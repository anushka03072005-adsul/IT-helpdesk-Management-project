# IT-helpdesk-Management-project
It allows employees to raise IT-related issues as tickets, such as hardware, software, network, email, or access problems. The employee can provide the issue details, select its category and priority, and then track the status of their ticket and add comments.

On the IT team side, team members can view all submitted tickets, search and filter them, assign tickets to IT members, update their priority and status, add resolution notes, and finally close the ticket.

So, in short, the system provides a centralized way for employees to report IT problems and for the IT team to manage and resolve those problems.
